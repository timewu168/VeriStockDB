# 歷史封存 Notice

此目錄是舊版 handoff 與規劃資料封存區，不是目前專案狀態來源。

## 使用規則

- 只作歷史追溯、需求脈絡或舊決策參考。
- 不可用此目錄內的 `README.md`、`CHANGELOG.md`、`PROJECT_HANDOFF.md`、`PROJECT_STATE.json` 覆蓋目前狀態。
- 不可從此目錄推導目前已完成資料表、正式排程、版本號或部署路徑。
- 若此目錄內容與根目錄文件衝突，以根目錄文件為準。

## 目前權威文件

- `../../CURRENT_STATE.md`：下一輪接手唯一上下文摘要。
- `../../README.md`：目前 public 專案說明。
- `../../CHANGELOG.md`：唯一正式 release history。
- `../README.md`：文件入口與判讀優先順序。
- `../local_truth_api_spec.md`：目前 Local Truth API 契約。
- `../version_roadmap_checklist.md`：目前版本路線與完成條件。

## 封存原因

此目錄保留早期 `v0.3.x` 左右的交接包、規劃書與狀態紀錄。專案後續已完成 Close、注意、處置、法人、資券、當沖、月營收、API、PWA 與 v0.6.x 收尾功能，因此舊文件可能落後。
